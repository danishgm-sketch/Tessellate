# Minimal Top Navigation
Restrained horizontal header with brand mark, essential route links, and profile badge.

In narrow containers, navigation collapses behind an accessible Menu button. The menu opens from the keyboard or touch, Escape closes it and restores focus, and expanded mobile rows are at least 44px tall. Wider containers keep the links visible inline.

Pass `links` with real `href` values to enable navigation. Items without a destination render as labels.
