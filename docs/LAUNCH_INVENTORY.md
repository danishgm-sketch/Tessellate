# 23. Production order inside each resource category

For any category, author resources in this sequence:

1. Most broadly useful fundamentals.
2. Structurally distinct alternatives.
3. High-ambition expressive resources.
4. Edge/niche patterns.

Never produce 50 near-identical resources solely to satisfy the numerical target.

Every resource must justify its existence through at least one of:

- different semantic role;
- materially different information architecture;
- materially different interaction model;
- materially different performance/complexity tradeoff;
- materially different visual ambition;
- materially different device/responsive behaviour.
