## Security headers

The Sites Worker routes public HTML through the edge adapter and uses no-transform to preserve the vetted artifact. Packaging hashes inline scripts and style elements across all 716 public HTML files, excluding the isolated `/preview` adapter and `/preview-content` renderer. `/preview` is a small trusted wrapper; the actual React renderer runs in a child iframe with both an iframe `sandbox="allow-scripts"` attribute and a response-level `sandbox allow-scripts` CSP. Top-level browser navigations to `/preview-content` are redirected to the wrapper. The renderer has an opaque origin and cannot access the application DOM or storage. Its CSP blocks arbitrary network connections, nested frames, and external assets; the only `connect-src` exception is the same-origin immutable `/_astro/` asset path used by its stylesheet preload. The child renderer response omits `frame-ancestors` and `X-Frame-Options` because the intentionally opaque sandbox parent cannot satisfy a same-origin ancestor check; sandboxing remains enforced on the response and iframe, and the E2E suite verifies DOM/storage isolation and blocked navigation.

The app embeds `/preview-content` directly for interactive resource details and catalogue cards. The renderer validates that updates come from its direct parent and that the message sender has the Site origin; its own opaque origin is not the sender origin. READY/resize/error messages flowing back to the app are accepted only from the matching iframe with the expected opaque `null` origin. The top-level `/preview` wrapper supplies initial state from the URL and is a read-only display boundary.

Preview CSP also explicitly sets `form-action 'none'`, and the app shell allows only same-origin form destinations. A desktop/mobile Playwright probe attempted to submit a field to an intercepted external collector: no request was emitted. Before the explicit directive was added, the opaque sandbox already blocked submission, but the header had no dedicated form-action rule. Registry admission now also rejects unresolved `action`, `formAction`, and `ping` props; shared link, button, and input primitives strip those forwarding props.

The deployed review Site was probed on 2026-10-21 at 1440x900 and 390x844. It still serves the previous broad app-shell policy with unsafe-inline in script-src and style-src; a harmless injected inline script executed on the deployed home page. The local fix passes the desktop/mobile CSP suite and the full E2E suite, but this finding remains open until the fixed version is deployed and verified at the Step 45 release-candidate gate.
